# Uso de herramientas de inteligencia artificial

El equipo puede utilizar herramientas de IA como apoyo para explorar,
implementar, documentar y depurar BeanRunner. La responsabilidad de entender,
revisar y aceptar cada cambio pertenece al equipo; una salida de IA no es por
sí misma una decisión de arquitectura ni evidencia de funcionamiento.

Los registros describen el alcance de una interacción, los cambios
relacionados y las verificaciones ejecutadas. No atribuyen revisiones o
aprobaciones individuales que no estén documentadas. Cada integrante debe
revisar el código que presentará y poder explicar su funcionamiento.

## Criterio de uso

Antes de integrar una propuesta, el equipo debe revisar su compatibilidad con
los requisitos, ejecutar pruebas apropiadas y registrar limitaciones reales.
Los reportes de prueba identifican el entorno en que se ejecutaron; no se
generalizan resultados de Windows a Linux/WSL2 ni viceversa.
