# TC-004: Listar y filtrar trabajos locales

* **Requisitos cubiertos:** RF-09
* **Objetivo:** Comprobar el listado de trabajos registrados y el filtrado por estado.
* **Precondiciones:** BeanRunner iniciado en modo interactivo o `JobRunner` creado en memoria.

## Pasos de ejecución
1. Enviar al menos un trabajo corto y otro de larga duración.
2. Ejecutar `list` para mostrar todos los trabajos.
3. Ejecutar `list RUNNING` mientras el trabajo largo siga activo.
4. Esperar a la terminación y ejecutar `list SUCCEEDED`.
5. Ejecutar `list INVALID` para comprobar el rechazo de un estado desconocido.

## Resultado esperado
* El listado incluye ID, PID, estado, código de salida cuando esté disponible y comando.
* El filtro devuelve únicamente trabajos que coinciden con el estado solicitado.
* Un listado vacío se informa sin excepción.
* Un filtro inválido muestra los estados admitidos y mantiene activa la sesión.

## Resultado observado
Las pruebas unitarias de listado vacío y filtro de estado en
`tests/test_manager.py` pasaron en Windows con Python 3.14.3. La demostración
manual en Linux/WSL2 queda pendiente de registrar.
