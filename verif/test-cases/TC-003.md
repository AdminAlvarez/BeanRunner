# TC-003: Consulta de estado y captura de código de salida

* **Requisitos Cubiertos:** RF-06, RF-07, RF-08[cite: 4, 14]
* **Objetivo:** Verificar el ciclo de vida de un trabajo que finaliza con éxito y la recuperación de su exit code ($0$)[cite: 4, 14].
* **Precondiciones:** Trabajo registrado e iniciado[cite: 4].

### Pasos de Ejecución
1. Enviar el trabajo `echo "Hola"`.
2. Consultar periódicamente el estado usando el `job_id` asignado (RF-08)[cite: 4].
3. Esperar a que el proceso hijo concluya[cite: 4].

### Resultado Esperado
* El trabajo transiciona de `RUNNING` a `SUCCEEDED`[cite: 4].
* El atributo `exit_code` almacena el valor `0` y se registran los timestamps `started_at` y `finished_at` (RF-07)[cite: 4].
