# TC-003: Consulta de estado y captura de código de salida

* **Requisitos Cubiertos:** RF-06, RF-07, RF-08
* **Objetivo:** Verificar el ciclo de vida de un proceso que finaliza con éxito y la recuperación de su código de salida (`0`).
* **Precondiciones:** Trabajo registrado e iniciado.

### Pasos de Ejecución
1. Enviar un comando Python que imprima `Hola` y termine con código `0`.
2. Consultar periódicamente el estado usando el `job_id` asignado (RF-08).
3. Esperar a que el proceso hijo concluya.

### Resultado Esperado
* El trabajo transiciona de `RUNNING` a `SUCCEEDED`.
* El atributo `exit_code` almacena el valor `0` y se registran los timestamps `started_at` y `finished_at` (RF-07).

### Resultado Observado
La prueba automatizada correspondiente en `tests/test_job_runner.py` pasó en
Windows con Python 3.14.3. El recorrido manual en Linux/WSL2 queda pendiente
de registrar.
