# TC-002: Rechazo de comandos vacíos o malformados

* **Requisitos Cubiertos:** RF-02, RNF-08
* **Objetivo:** Confirmar que las solicitudes inválidas sean rechazadas explícitamente sin colapsar el servicio daemon.
* **Precondiciones:** Sesión interactiva de BeanRunner en ejecución.

### Pasos de Ejecución
1. En la sesión interactiva, enviar un comando con comillas incompletas: `submit echo "test`.
2. Confirmar que se presenta un error entendible y no se registra un trabajo.
3. Enviar después un comando válido, por ejemplo `submit python -c "print('sigue activo')"`.
4. Consultar el listado y comprobar que el trabajo válido fue aceptado.

### Resultado Esperado
* La entrada inválida se rechaza con un mensaje controlado (`ValueError` en el componente y mensaje en la CLI).
* La sesión sigue respondiendo y acepta el siguiente comando válido (RNF-08).

### Resultado Observado
La recuperación se comprueba en `tests/test_submitter.py` y `tests/test_main.py`;
ambas forman parte de las 19 pruebas unitarias aprobadas en Windows con Python
3.14.3. El recorrido manual en Linux/WSL2 queda pendiente de registrar.
