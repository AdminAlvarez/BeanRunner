# TC-002: Rechazo de comandos vacíos o malformados

* **Requisitos Cubiertos:** RF-02, RNF-08[cite: 4, 7]
* **Objetivo:** Confirmar que las solicitudes inválidas sean rechazadas explícitamente sin colapsar el servicio daemon[cite: 4, 7].
* **Precondiciones:** Servicio en ejecución[cite: 14].

### Pasos de Ejecución
1. Enviar una cadena vacía: `submit_job("")`[cite: 4].
2. Enviar una cadena de solo espacios: `submit_job("   ")`[cite: 4].
3. Enviar un comando con sintaxis inválida (ej. comillas incompletas): `submit_job('echo "test')`[cite: 4].

### Resultado Esperado
* El sistema lanza una excepción controlada (`ValueError`) o mensaje de error descriptivo (RF-02)[cite: 4].
* El proceso Daemon continúa respondiendo y no se interrumpe (RNF-08)[cite: 7].
