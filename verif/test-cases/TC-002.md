# TC-002: Rechazo de comandos vacíos o malformados

* **Requisitos Cubiertos:** RF-02, RNF-08
* **Objetivo:** Confirmar que las solicitudes inválidas sean rechazadas explícitamente sin colapsar el servicio daemon.
* **Precondiciones:** Servicio en ejecución.

### Pasos de Ejecución
1. Enviar una cadena vacía: `submit_job("")`.
2. Enviar una cadena de solo espacios: `submit_job("   ")`.
3. Enviar un comando con sintaxis inválida (ej. comillas incompletas): `submit_job('echo "test')`.

### Resultado Esperado
* El sistema lanza una excepción controlada (`ValueError`) o mensaje de error descriptivo (RF-02).
* El proceso Daemon continúa respondiendo y no se interrumpe (RNF-08).

PASS
