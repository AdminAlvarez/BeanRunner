# TC-006: Registrar resultado y código de salida

* **Requisitos cubiertos:** RF-06, RF-07, RF-11
* **Objetivo:** Comprobar que el resultado del proceso hijo se refleja en el estado del trabajo.
* **Precondiciones:** BeanRunner disponible localmente.

## Pasos de ejecución
1. Enviar un comando Python que imprima texto y termine con código `0`.
2. Consultar el estado hasta que sea terminal y revisar `output <job-id>`.
3. Enviar un comando Python que termine con código `7`.
4. Consultar su estado y metadatos.

## Resultado esperado
* El primer trabajo termina como `SUCCEEDED`, registra código `0` y captura stdout separado de stderr.
* El segundo trabajo termina como `FAILED` y registra código `7`.
* Ambos trabajos registran tiempos de inicio y terminación.

## Resultado observado
Las pruebas de código de salida cero/no cero y captura de salida en
`tests/test_job_runner.py` pasaron en Windows con Python 3.14.3. La
demostración manual en Linux/WSL2 queda pendiente de registrar.
