# TC-001: Enviar trabajo válido y obtener ID único

* **Requisitos Cubiertos:** RF-01, RF-02
* **Objetivo:** Verificar que el sistema acepte un comando bien formado y devuelva un identificador único (UUID v4) en estado QUEUED.
* **Precondiciones:** El módulo `JobSubmitter` o el daemon están activos.

### Pasos de Ejecución
1. Invocar el método o comando de envío: `submit_job("sleep 10")`.
2. Comprobar el formato del valor de retorno.
3. Consultar el registro en la memoria o base de datos interna.

### Resultado Esperado
* Retorna una cadena con formato UUID v4 de 36 caracteres.
* El trabajo queda registrado internamente con `status = QUEUED`
